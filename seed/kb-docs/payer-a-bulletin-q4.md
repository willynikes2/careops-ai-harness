This quarterly bulletin describes administrative changes for Payer A in the CareOps synthetic demonstration. Billing staff should review the authorization routing update and holiday processing schedule when planning open work. The bulletin supplements the provider manual; it does not replace the prior-authorization requirement or change filing and response deadlines.

## §1 New fax number for authorization requests

The new fax number for authorization requests is **202-555-0142**. This is a fictional demonstration number and must not be used to transmit documents. In the synthetic workflow, use the new routing reference when describing an authorization follow-up and retire any older routing reference from working notes.

Check that the request relates to the intended claim and that the authorization records are complete before recording the handoff. Retain the submission reference in the billing workflow so staff can follow the request without guessing whether the material was sent. A routing update does not remove the need to obtain authorization before the first skilled home-health visit.

## §2 Holiday processing schedule

The synthetic authorization desk will pause routine processing on **November 26–27, 2026**, and **December 24–25, 2026**. Routine processing resumes on the next business day. Plan document collection and internal review ahead of these dates, especially for claims with an approaching response deadline.

The holiday schedule does not extend the **30-day** deadline for a retro-authorization request after a denial or the **90-day** timely filing window. Record the relevant deadline in the follow-up workflow and ask the billing supervisor to review cases that need attention before the processing pause. Keep an existing task's next step clear when work is handed to another staff member.
